Chimp.OS section
http://127.0.0.1:43123/

Start

python3 server/vault.py

Leave that process running. Port 43123, or set PORT. Data: data/vault.sqlite. Photos: data/photos/.

If the browser says connection refused

curl -sv --max-time 3 http://127.0.0.1:43123/api/v1/health
ps aux | grep vault.py

Refused means the process is down. Start it again. A running server answers {"ok": true}.

File and export

curl -s http://127.0.0.1:43123/api/v1/jobs
curl -s -o vault.csv http://127.0.0.1:43123/api/v1/export.csv
curl -s -X POST http://127.0.0.1:43123/api/v1/batch/file \
  -H 'Content-Type: application/json' -d '{}'

On the queue screen, Add photos drops a picture in. No vision key: it waits as “Needs a title.” Set VISION_API_KEY or OPENAI_API_KEY to read the photo. On a case, Price guide hits Scryfall. File it saves the label.
